# Imported UI Paste Zone

Drop external shadcn-style `components/ui/*` files here **as-is**.

**Pre-installed stack:** Radix UI, framer-motion, lucide-react, vaul, cmdk, sonner, cva, tailwind-merge, `tw-animate-css` — see `apps/web/package.json` and `presentation-import/presentation-deps.ts`.

Do not import from `@phonara/ui` inside this folder — keep imported visuals isolated.
